# MANIFEST.md — what every file is for

Read this instead of re-reading source. If a file is listed here, you already know
enough to work with it; open it only when you are about to change it.

## Documents

| File | Purpose |
|------|---------|
| `PLAN.md` | Architecture, phases, fidelity targets, risk register. §0 (the reducer) is load-bearing. |
| `TONE.md` | The voice. Ten reference lines, three hard lines, craft rules, voice table. Every writer matches it. |
| `STATE.md` | Where we are. Rewritten every phase, for a reader with no memory. |
| `MANIFEST.md` | This file. |
| `BLOCKERS.md` | Anything that failed a gauntlet three times, with diagnosis. |
| `DEPLOY.md` | Exact Firebase steps for the human to run. Claude never logs in. |

## `src/core` — pure logic, no DOM, no imports outside core

| File | Purpose |
|------|---------|
| `rng.ts` | Seeded xorshift128+, serializable into the save. `Math.random` is banned in core. |
| `types.ts` | The 12-type chart on three axes (weapon / habitat / temperament) + effectiveness lookups. |
| `creature.ts` | `Species`, `Move`, `Feral` shapes; stat, damage, exp and catch maths. The content contract. |
| `battle.ts` | Turn resolution state machine. Emits a typed event stream the UI animates and the sim asserts on. |
| `world.ts` | Tile grid, tile property table, collision, ledges, warps, encounter tables, trainer line of sight. |
| `game.ts` | The top-level reducer. `step(content, state, buttons)` = one frame. Save file is this state. |
| `testkit.ts` | Shared helpers for gauntlets: `makeDex`, `makeFeral`, `autoBattle`. |
| `save.ts` | Serialize / deserialize / migrate. |

## `src/render` — drawing only, never rules

| File | Purpose |
|------|---------|
| `forge.ts` | Procedural sprite generator. Family skeleton + parameterized parts + coat pattern, from a seed. Runs in Node and browser. Shade 3 is reserved for outline/eye/nose. |
| `gb.ts` | DMG palette, 8×8 font, bordered windows, text box, tile art, sprite blitting. 160×144, integer scale. |
| `draw.ts` | `draw(ctx, content, state)` — pure function of game state. |

## `src/data` — generated content. Never hand-edit a `.gen.ts`.

| File | Generated by | Contents |
|------|--------------|----------|
| `moves.gen.ts` | `scripts/gen/moves.ts` | 96 moves, 8 per type. |
| `species.gen.ts` | `scripts/gen/species.ts` | 153 species: stats, learnsets, evolutions, catch rates, sprite seeds. |
| `maps.gen.ts` | `scripts/gen/maps.ts` | Every map: tiles, warps, NPCs, encounter tables. |
| `trainers.gen.ts` | `scripts/gen/maps.ts` | Every trainer, gym leader, Elite Four member and the Champion. |
| `dialogue.gen.ts` | hand-written | Every line in the game. The one thing that is written, not generated. |

## `scripts/gen` — content generators

| File | Purpose |
|------|---------|
| `roster.ts` | The hand-authored 153-creature table: id, animal, family, types, stage, archetype, evolution, dex entry. No numbers. |
| `species.ts` | The statline generator. ~20 tuning knobs at the top produce all 153 statlines and learnsets. |
| `moves.ts` | Move table generator. |
| `maps.ts` | World generator. Encounter tables select species by filter, not by hardcoded id. |

## `scripts/gauntlet` — the eight hard gates

| File | Gate |
|------|------|
| `types.ts` | strict tsc, eslint, zero `any`, no suppressions, plus core purity invariants. |
| `schema.ts` | All 153 creatures validate. Verified against 68 deliberately planted defects. |
| `sim.ts` | 10,000 self-play battles. Move/creature/type win-rate bands, turn budget, starter parity. |
| `curve.ts` | Each gym beatable at its intended level and not twenty levels under. Monotonic. |
| `playthrough.ts` | **The one that defines done.** Headless bot plays to Champion on real inputs, once per starter. |
| `visual.ts` | Playwright screenshots at story checkpoints + contact sheet, graded against Red/Blue. |
| `tone.ts` | Every dialogue line graded cold; enforces the three hard lines. |
| `ship.ts` | Production build, real load, save/reload survives, Lighthouse mobile ≥ 90. |
| `all.ts` | Runs all eight. This passing is the only definition of finished. |
