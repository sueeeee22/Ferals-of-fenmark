# Ferals of Fenmark — read this first

Browser creature-collector benchmarked on Pokémon Red/Blue. Live: https://sueeeee22.github.io/Ferals-of-fenmark/

## Hard rules (non-negotiable)
- All human characters are adults. Full stop.
- The creatures are never sexualized, ever, in any way. The horny lives entirely in the human dialogue. Nobody is fucking a dog — that isn't the bit, and the bit is funnier without it.
- Explicit acts fade to black.
- 150 real animals, no Pokémon names/designs. Protagonist Tabitha Astacio (adult, funniest person in the room). Starters: Winter (black/white husky, Fang/Frost, aloof), Baloo (orange/white husky, Fang/Ember, enthusiastic idiot), Plato (grey/white tabby, Claw/Hearth, contemptuous). Game of Thrones register; filthy, fast dialogue (see TONE.md).
- Never log into Firebase. Never create a PR unless asked.

## Workflow
- Develop on `claude/ferals-fenmark-rpg-ga42yt`. Deploying = fast-forward `main` to it and push; CI publishes `main` to GitHub Pages. The user has approved this.
- Talk to the user in plain language. They are a vibe coder: skip jargon, and only explain what went wrong when it helps them make the game better.
- `npm run gauntlet` runs all 9 gates. The player-facing proof is a real browser: data-level tests have repeatedly passed while the screen was broken (invisible sprites, cut-off text, HP bars out of sync). Verify OUTPUT, not just data.

## Architecture in one breath
`src/core` = pure deterministic reducer `step(content, state, buttons)` (no DOM, no Math.random — enforced). `src/render` = draws state. `src/audio` = synthesised Game Boy chip; reads state the same way. Sprites are procedural (`src/render/forge.ts`). Content is generated by `scripts/gen/*` into `src/data/*.gen.ts` — edit the generator, then `npm run gen:all`.
